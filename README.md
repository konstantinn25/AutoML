# Cистема автоматической конфигурации AutoML-пайплайнов на основе запросов на естественном языке

Система позволяет пользователю описать ML-задачу на естественном языке и автоматически сформировать конфигурацию ML-пайплайна, соответствующую задаче и предпочтениям пользователя

## План разработки

> [!Note]
> Разработка проекта будет проходить поэтапно в соответствии с чекпойнтами годового проекта. На каждом этапе система будет постепенно развиваться от базового ML-ядра до полноценного сервиса автоматической конфигурации ML-пайплайнов.

### 1. Исследование и подготовка данных

- Выбор датасетов для разработки и тестирования
- Анализ типов признаков, пропусков, дубликатов и выбросов
- Исследование распределений и целевой переменной
- Определение характеристик датасета, которые в дальнейшем будут использоваться системой при выборе пайплайна

### 2. Разработка базового ML-ядра

- Реализация задач классификации и регрессии
- Создание модулей предобработки данных
- Подключение базовых ML-моделей
- Определение и реализация метрик качества
- Подбор гиперпараметров

### 3. Создание ML-сервиса

- Разработка ML-сервиса на FastAPI
- Реализация загрузки датасетов, анализа данных и запуска обучения
- Создание пользовательского интерфейса
- Реализация полного сценария от загрузки датасета до получения результатов

### 4. Разработка автоматической конфигурации на естественном языке

- Разработка формата пользовательских запросов
- Определение структуры конфигурации ML-задачи
- Реализация преобразования запроса на естественном языке в структурированную конфигурацию
- Добавление валидации сформированной конфигурации
- Реализация автоматической генерации пайплайна

### 5. Интеграция нейросетевых моделей

- Реализация нейросетевых моделей для табличных данных
- Подбор архитектур и гиперпараметров
- Интеграция нейросетей в общий механизм автоматической конфигурации

### 6. Интеграция MLFlow и контроль воспроизводимости

- Подключение MLflow
- Реализация логирования параметров, метрик, моделей и артефактов
- Реализация сохранения конфигураций экспериментов
- Реализация фиксации версий зависимостей и параметров запуска

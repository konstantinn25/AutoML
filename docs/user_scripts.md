## 2. Матрица покрытия: 40 пользовательских сценариев

**Принцип:** один сценарий = запрос пользователя + датасет + ручной эталон. **Тип формулировки** - основной вид проверки, категории могут пересекаться. Если информации недостаточно или запрос противоречив, эталонное решение - уточнение либо остановка, а не вымышленная конфигурация. Сценарии ориентированы на возможности целевой системы: подготовка таргета, агрегация и соединение нескольких таблиц могут требовать отдельного этапа обработки данных перед запуском AutoGluon. Подробное описание составления тестовых запросов приведено в [документе](./test_generation.md).
